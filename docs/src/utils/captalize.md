# `src/utils/captalize.tsx`

> Capitalização de texto para exibição (primeira letra maiúscula).

## O que faz

- `capitalize(str)` — deixa apenas a primeira letra maiúscula.
- `capitalizeWords(str)` — capitaliza cada palavra separada por espaço.

## Relações

- **Usado por:** páginas `index`, `historico` e `resumo`; componentes `summary/MonthlyConsolidation` e `payables/PayablesHeader`.
