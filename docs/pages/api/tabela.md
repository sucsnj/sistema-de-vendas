# `src/pages/api/tabela.ts`

## Descrição

API REST para cadastro e histórico de tabelas de vendas/importação.

## Métodos

- `GET` - retorna histórico de tabelas.
- `POST` - salva uma tabela processada pelo frontend.

## Observações

- O endpoint é usado pela tela de upload/consulta de tabelas.
- Garante que cada tabela seja persistida com data e origem.
