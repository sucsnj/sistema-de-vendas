# `src/pages/api/mensais.ts`

## Descrição

API para relatórios mensais de vendas consolidadas.

## Métodos

- `GET` - busca dados mensais de vendas agregadas por `mes` e `ano`.

## Observações

- Usado no painel de resumo para gerar tabelas e totais mensais.
- Devolve coleção de registros mensais para o frontend.
